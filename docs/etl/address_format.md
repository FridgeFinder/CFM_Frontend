# Address Format

- Argentina (AR): Street + Number, Postal Code + Locality, Province, Country (Postal code: 4 digits + 3 letters optional)
- Australia (AU): Unit/Street Number + Street, Suburb, State, Postcode, Country (Postcode: 4 digits)
- Belgium (BE): Street + Number, Postal Code + Municipality, Country (Postal code: 4 digits)
- Brazil (BR): Street + Number, District, City, State, Postal Code, Country (Postal code: 8 digits XXXXX-XXX)
- Canada (CA): Unit/Street Number + Street, City, Province, Postal Code, Country (Postal code: A1A 1A1 format)
- China (CN): Province, City, District, Street, Building Number, Postal Code (Postal code: 6 digits)
- Colombia (CO): Street + Number, City, Department, Postal Code, Country (Postal code: 6 digits)
- Denmark (DK): Street + Number, Postal Code + City, Country (Postal code: 4 digits)
- Egypt (EG): District, City, Governorate, Postal Code, Country (Postal code: 5 digits)
- France (FR): Street Number + Street, Postal Code + City, Country (Postal code: 5 digits)
- Germany (DE): Street + Number, Postal Code + City, Country (Postal code: 5 digits)
- Iceland (IS): Street + Number, Postal Code + City, Country (Postal code: 3 digits)
- India (IN): House/Street, Area, City, State, PIN Code, Country (PIN: 6 digits)
- Israel (IL): Street + Number, City, Postal Code, Country (Postal code: 7 digits)
- Italy (IT): Street, Postal Code, City, Province, Country (Postal code: 5 digits)
- Japan (JP): Postal Code, Prefecture, City, District, Street + Number, Country (Postal code: 7 digits XXX-XXXX)
- Lebanon (LB): District, City, Postal Code, Country (Postal code: 4 digits optional, 8 digits XXXX XXXX)
- Lithuania (LT): Street + Number, City, Postal Code, Country (Postal code: 5 digits LT-XXXXX)
- Netherlands (NL): Street + Number, Postal Code + City, Country (Postal code: 4 digits + 2 letters 1234 AB)
- New Zealand (NZ): Unit/Street Number + Street, Suburb, City, Postcode, Country (Postcode: 4 digits)
- Saudi Arabia (SA): District, City, Postal Code, Country (Postal code: 5 digits)
- Singapore (SG): Block + Street Name, Unit Number, Postal Code, Country (Postal code: 6 digits)
- Slovakia (SK): Street + Number, Postal Code + City, Country (Postal code: 5 digits XXX XX)
- Switzerland (CH): Street, Postal Code, City, Canton, Country (Postal code: 4 digits)
- Thailand (TH): House Number + Street, Subdistrict, District, Province, Postal Code, Country (Postal code: 5 digits)
- United Kingdom (GB): Building/Street, Locality, Town/City, Postcode, Country (Postcode: various formats)
- USA (US): Street + Number, City, State, ZIP Code, Country (ZIP: 5 or 9 digits)
- Vietnam (VN): House Number + Street, Ward, District, City/Province, Postal Code, Country (Postal code: 6 digits)
